# Motion · MPU6050 실습

MPU6050의 가속도 3축·각속도 3축·내부 온도를 USB로 읽고 그래프와 3D 자세를 관찰합니다.
동작을 라벨별로 수집해 센서 CSV로 저장할 수 있습니다.

## 다운로드와 업로드

1. [모션 실습 페이지](https://midnightradio.github.io/physical-ai-lab/motion/)의 **보드 코드 ZIP 다운로드**를 누릅니다.
2. 압축을 해제하고 `esp32_motion_capture/esp32_motion_capture.ino`를 Arduino IDE로 엽니다.
3. 보드 매니저에서 **esp32 by Espressif Systems 3.x**를 설치합니다.
4. 라이브러리 매니저에서 **Adafruit MPU6050**과 제안되는 의존 라이브러리를 설치합니다.
5. 아래 보드와 USB 설정을 선택해 업로드합니다.
6. 시리얼 모니터·플로터를 닫고 실습 페이지에서 **USB 보드 연결**을 누릅니다.

두 보드는 같은 스케치를 사용합니다. 보드 선택에 따라 SDA 핀이 정해집니다.
다른 실습 코드가 올라가 있다면 모션 코드를 먼저 업로드하세요.

## 보드 설정과 배선

| 항목 | XIAO ESP32S3 | 강의의 WROOM N16R8 |
| --- | --- | --- |
| Arduino 보드 | `XIAO_ESP32S3` | `ESP32S3 Dev Module` |
| Flash Size | 8MB | 16MB |
| PSRAM | OPI PSRAM | OPI PSRAM |
| SDA | D4 / GPIO5 | GPIO7 |
| SCL | D5 / GPIO6 | GPIO6 |

- 직접 USB: **USB Mode = Hardware CDC and JTAG**, **USB CDC On Boot = Enabled**.
- USB-UART 변환 포트: **USB CDC On Boot = Disabled**.
- 업로드와 수집에 같은 포트를 사용합니다.

USB 전원을 분리하고 GND와 SDA·SCL을 연결합니다.
VCC는 **3.3V 입력을 지원하는 모듈이면 3V3**에 연결합니다. 모듈의 VCC 입력 사양과
ESP32에 연결되는 SDA/SCL 풀업 전압이 3.3V인지 확인합니다.

기본 주소는 `0x68`이므로 **AD0를 GND에 연결**합니다.
AD0가 3V3이면 코드의 `MPU_ADDRESS`를 `0x69`로 바꿉니다. 이 버전은 주소를 자동 탐색하지 않습니다.

강의의 Freenove WROOM CAM은 카메라가 GPIO6·7을 사용합니다.
모션 실습 전에 전원을 분리한 상태에서 카메라 리본 케이블과 앞선 INMP441 배선을 제거합니다.

## 관찰과 수집

1. 센서를 수평으로 놓고 **정지 보정 · 2초**를 누릅니다.
2. 기울이기·회전·위아래 흔들기로 가속도와 각속도의 차이를 관찰합니다.
3. 동작 라벨·학생/세션 ID·수집 시간을 지정합니다.
4. 3축 또는 6축을 선택하고 **동작 수집 시작**을 누릅니다.
5. **CSV 저장 형식**을 선택하고 센서 CSV 또는 전체 CSV ZIP으로 저장합니다. 학습·테스트 구분은 수집 후 정리합니다.

센서 없이 살펴보려면 **센서 없이 체험**을 사용합니다. DEMO 데이터는 실제 측정값과 구분됩니다.
3D는 추정 자세이며 Yaw는 절대 방위가 아닙니다. 위치·이동거리를 측정하지 않습니다.
추정각도는 센서 CSV에 저장하지 않습니다. 가속도는 g, 각속도는 °/s입니다.
수집 데이터는 이 창의 메모리에 있으므로 새로고침 전에 저장하세요.

## Edge Impulse에 모션 데이터 올리기

기본 **Edge Impulse용 · 50Hz** 형식은 첫 열이 `timestamp`(ms), 나머지 열이
`accX,accY,accZ` 또는 `accX,accY,accZ,gyrX,gyrY,gyrZ`인 시계열 CSV입니다.
파일 하나에 수집 구간 하나를 저장하고, 파일명 첫 마침표 앞을 동작 라벨로 사용합니다.

실제 측정 간격의 작은 차이는 센서값을 **선형 보간**해 `0,20,40,...ms`의 일정한
50Hz 간격으로 맞춥니다. 마지막 측정 시각 밖으로 값을 연장하지 않습니다.
40ms를 넘는 수신 누락이나 샘플 부족은 다운로드 시 안내하므로 재수집하세요.
브라우저에 보관한 원래 행과 실시간 그래프는 바꾸지 않습니다.
**센서 원측정값 · 실제 시각**을 선택하면 기존처럼 실제 측정 시각과 값을 보존할 수 있습니다.
이 형식은 시간 간격이 일정하지 않을 수 있습니다.

1. ZIP으로 저장했다면 압축을 풉니다.
2. `data/3axis` 또는 `data/6axis` 중 같은 축 구성의 CSV만 선택합니다.
3. Edge Impulse의 **Data acquisition → Upload data**에서 업로드합니다.
4. 파일명에서 라벨을 가져오는 설정을 선택하고, 라벨과 샘플 주파수 50Hz를 확인합니다.

가속도 단위는 **g**, 각속도는 **°/s**입니다. m/s²로 자동 변환하지 않으므로
학습과 추론에서 축 순서와 단위를 동일하게 사용하세요. 기존 CSV Wizard 설정이 있다면
`timestamp`를 ms로 읽고 센서축을 올바르게 매핑하는지 확인합니다.
CSV에 온도·자세각·학습/테스트 용도 열은 추가하지 않습니다.

`dataset.json`과 안내문은 Edge Impulse에 업로드하지 않습니다. JSON에는 저장 형식과
보간 방법, 원래 행 수(`sampleCount`), CSV 행 수(`exportedSampleCount`), 실제 수집 주파수와
학생/세션을 기록합니다. DEMO 데이터는 실제 학습·평가에서 제외하고, `.partial.csv`는 품질을 확인합니다.
학습·테스트는 업로드 전에 파일·학생·세션 단위로 나눕니다.

공식 규격: [Edge Impulse CSV](https://docs.edgeimpulse.com/tools/specifications/data-acquisition/csv)

## 시리얼 플로터로 먼저 보기

업로드 직후 **115200 baud** 시리얼 플로터에서 이름이 붙은 6축 값을 볼 수 있습니다.
웹 수집기에 연결하면 CSV 통신으로 전환됩니다. 플로터로 돌아갈 때는 브라우저 연결을 해제하고,
시리얼 모니터에서 `p`를 보낸 뒤 모니터를 닫고 플로터를 엽니다.

실제 보드의 배선·업로드·수집 상태는 실습 전에 확인하세요.
