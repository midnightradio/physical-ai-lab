실습 준비 · 모션 보드 코드

처음 연결하거나 실습을 바꿨다면, 이 실습의 코드를 먼저 업로드하세요.

보드 코드 ZIP 다운로드 ↓
보드 설정과 업로드 순서 보기
  1. 코드 ZIP을 압축 해제하고 esp32_motion_capture/esp32_motion_capture.ino를 Arduino IDE에서 엽니다.
  2. 보드 매니저에서 esp32 by Espressif Systems 3.x를 설치합니다. Adafruit MPU6050과 제안되는 의존 라이브러리도 설치합니다.
  3. 보드는 XIAO이면 XIAO_ESP32S3, WROOM이면 ESP32S3 Dev Module로 선택합니다. Flash는 XIAO 8MB, WROOM N16R8 16MB로 선택합니다.
  4. 직접 USB는 USB Mode = Hardware CDC and JTAG, USB CDC On Boot = Enabled. USB-UART 포트는 USB CDC On Boot = Disabled로 설정합니다.
  5. 업로드 후 시리얼 모니터와 플로터를 닫고, 아래에서 USB 보드를 연결합니다.

MPU6050: XIAO는 SDA=GPIO5, SCL=GPIO6 / WROOM은 SDA=GPIO7, SCL=GPIO6. AD0는 기본 GND입니다.

INO 파일만 다운로드배선·실습 안내 ↗
USB 연결은 PC용 Chrome 또는 Edge에서 이 페이지를 열어 사용하세요. 아래의 센서 없이 체험은 USB 없이도 사용할 수 있습니다.

03수집한 데이터 0개

CSV에는 시간과 선택한 3축 또는 6축의 센서 측정값을 저장합니다. 이 창을 닫거나 새로고침하기 전에 저장하세요.

아직 수집한 동작이 없습니다.
처음 사용하시나요? · 배선, 보정, CSV와 문제 해결
  1. esp32_motion_capture.ino를 Arduino IDE에서 열고 Adafruit MPU6050과 의존 라이브러리를 설치합니다.
  2. 보드를 XIAO_ESP32S3 또는 ESP32S3 Dev Module로 선택해 업로드합니다. 시리얼 모니터와 플로터를 닫습니다.
  3. 이 페이지에서 USB 보드 연결을 누르고 포트를 선택합니다.
  4. 센서를 수평으로 놓고 정지 보정 · 2초를 누릅니다. 센서의 축 방향을 확인하며 기울이거나 회전시킵니다.
  5. 라벨·학생/세션·저장할 센서축을 지정해 수집하고 센서 CSV 또는 ZIP으로 저장합니다.

VCC3V3 입력 지원 모듈은 3V3. 모듈별 전원 정격 확인.
  • USB 직접 연결: USB Mode = Hardware CDC and JTAG, USB CDC On Boot = Enabled. USB-UART 포트 사용: USB CDC On Boot = Disabled. WROOM N16R8은 Flash=16MB, PSRAM=OPI입니다.
  • 강의의 Freenove WROOM CAM은 카메라가 GPIO6·7을 사용하므로 모션 실습 전에 카메라 리본 케이블을 분리하세요. 앞선 INMP441 배선도 분리합니다. SDA/SCL의 풀업 전압은 3.3V여야 합니다. 기본 코드에서는 AD0를 GND(0x68)에 연결합니다. AD0가 3V3이면 코드의 MPU_ADDRESS를 0x69로 변경합니다.
  • 센서를 정지시켜도 가속도에는 중력이 포함됩니다. 각속도는 회전하는 동안 변하고, 멈추면 0 근처로 돌아옵니다.
  • 정지 보정은 자이로의 일정한 오차를 3D 계산에서만 뺍니다. 현재 자세 0°는 모형의 기준을 바꾸며, 정지 보정을 대신하지 않습니다.
  • 자력계가 없으므로 Yaw는 절대 방위가 아닙니다. 오래 두면 회전 오차가 생길 수 있습니다. 빠른 흔들기 중에는 자세 추정이 덜 정확할 수 있습니다.
  • 그래프의 빈 구간은 수신 누락입니다. 실제 시각을 유지하며 임의의 샘플을 채우지 않습니다. 큰 간격이나 수신 오류가 있으면 다시 수집하세요.
  • CSV 첫 열 timestamp는 ms입니다. 가속도는 g, 각속도는 °/s입니다. CSV에는 선택한 센서축의 측정값만 저장합니다.
  • ZIP의 data/6axis 또는 data/3axis에서 같은 축 구성의 CSV를 모아 사용합니다. 학습·테스트 구분은 수집 후에 파일·학생·세션 단위로 진행하세요. 주파수는 50Hz, 축 개수와 단위는 수집·추론에서 일치시킵니다.
  • 예전 mpu6050_collect.ino의 7열 출력도 읽을 수 있지만 온도는 표시되지 않습니다. 이번 8열 코드 업로드를 권장합니다.
  • 데이터는 브라우저 메모리에만 보관됩니다. 촬영·녹음 도구처럼 CSV/ZIP 다운로드가 필요합니다. 서버 전송이나 Edge Impulse 자동 업로드는 수행하지 않습니다.
MPU6050 → USB → Chrome → CSV · 페이지를 연 뒤 관찰과 수집은 인터넷 없이 가능합니다.
