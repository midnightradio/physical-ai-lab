보드 코드 ZIP 다운로드 ↓
보드 설정과 업로드 순서 보기
  1. 코드 ZIP을 압축 해제하고 esp32_image_capture/esp32_image_capture.ino를 Arduino IDE에서 엽니다.
  2. 보드 매니저에서 esp32 by Espressif Systems 3.x를 설치합니다. 카메라 라이브러리는 보드 패키지에 포함되어 있습니다. PSRAM을 OPI로 활성화합니다.
  3. 보드는 XIAO이면 XIAO_ESP32S3, WROOM이면 ESP32S3 Dev Module로 선택합니다. Flash는 XIAO 8MB, WROOM N16R8 16MB로 선택합니다.
  4. 직접 USB는 USB Mode = Hardware CDC and JTAG, USB CDC On Boot = Enabled. USB-UART 포트는 USB CDC On Boot = Disabled로 설정합니다.
  5. 업로드 후 시리얼 모니터와 플로터를 닫고, 아래에서 USB 보드를 연결합니다.

XIAO는 Sense 확장 보드를 장착합니다. WROOM용 코드는 강의의 Freenove 계열 CAM 배선을 사용합니다.

Edge Impulse에 업로드

  1. 저장한 ZIP을 압축 해제합니다. 모든 사진은 images 폴더에 모여 있습니다.
  2. Edge Impulse Studio에서 Data acquisition → Upload data → Select a folder를 열고 images 폴더를 선택합니다.
  3. 학습용·테스트용 구분은 업로드할 때 또는 나중에 데이터를 정리할 때 지정하세요.
  4. 이미지 분류는 라벨을 파일명에서 추론 · Infer from filename으로 선택합니다. apple.s01.…jpg는 apple로 분류됩니다.
객체 검출 / FOMO 실습: 프로젝트의 라벨 방식을 Bounding boxes로 설정하고 사진을 업로드한 뒤, Labeling queue에서 객체마다 박스와 라벨을 지정하세요. 이 수집기는 박스를 자동으로 생성하지 않습니다.
페이지를 연 뒤 촬영·저장은 인터넷 없이 가능합니다. Edge Impulse 업로드는 Studio에서 진행하며, 그때 인터넷이 필요합니다.
처음 사용하는 경우 · 보드 설정과 문제 해결

esp32_image_capture.ino를 Arduino IDE에서 열고, 보드 패키지 esp32 by Espressif Systems 3.x를 사용하세요. 별도 카메라 라이브러리는 설치하지 않습니다.

보드Arduino 보드 선택메모리
XIAO ESP32S3 SenseXIAO_ESP32S3Flash 8MB · OPI PSRAM
강의의 WROOM N16R8 CAMESP32S3 Dev ModuleFlash 16MB · OPI PSRAM
  • 직접 USB / USB-OTG 포트: USB Mode = Hardware CDC and JTAG, USB CDC On Boot = Enabled.
  • USB-UART 포트: USB CDC On Boot = Disabled. 두 포트가 있으면 업로드·촬영에 같은 포트를 사용하세요.
  • 포트가 열리지 않으면 Arduino 시리얼 모니터·플로터, 다른 수집기 창을 닫으세요.
  • 카메라 초기화가 실패하면 PSRAM 설정, 보드 선택, 카메라 케이블 장착을 확인하세요.
  • 화면이 뒤집혔으면 좌우·상하 반전을 선택하세요. 저장하는 JPG에도 똑같이 적용됩니다.
  • 연속 촬영은 사진 한 장을 받은 뒤 다음 촬영을 시작합니다. 전송이 길어지면 선택한 간격보다 느려집니다.
  • 이 프로그램은 함께 제공된 이미지 수집 코드용입니다. CameraWebServer·오디오 수집 코드와는 통신 방식이 다릅니다.
WROOM용 핀 설정은 강의 자료의 Freenove 계열 CAM 보드 기준입니다. 다른 제조사 보드는 카메라 배선 확인이 필요합니다. 자세한 내용은 함께 제공된 학생 안내문을 참고하세요.
