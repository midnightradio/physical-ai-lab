공식 라이브러리로 ESP32 오디오 수집하기
=====================================

이 실습은 Espressif의 오픈소스 ESP_I2S 라이브러리를 직접 사용합니다.
핵심 함수는 microphone.recordWAV(초, &파일크기)입니다.
라이브러리가 녹음 데이터를 모으고 WAV 형식까지 만들어 줍니다.
esp32 보드 패키지에 들어 있으므로 별도의 오디오 라이브러리를 설치하지 않습니다.
교재 환경은 “esp32 by Espressif Systems” 3.3.12로 맞춥니다.

실습 파일
---------
audio_capture_xiao_sd/audio_capture_xiao_sd.ino
  XIAO ESP32S3 Sense의 마이크로 녹음하고, microSD에 WAV를 저장합니다.
  브라우저나 수업용 연결 파일 없이 공식 ESP_I2S와 SD만 사용하는 기초 예제입니다.

audio_capture_xiao_usb/audio_capture_xiao_usb.ino
  XIAO ESP32S3 Sense의 마이크로 녹음하고 기존 오디오 수집기로 보냅니다.

audio_capture_inmp441_usb/audio_capture_inmp441_usb.ino
  ESP32-S3-WROOM-1 N16R8 CAM 개발보드와 INMP441로 녹음하고 수집기로 보냅니다.
  INMP441의 입력 변환도 공식 라이브러리의 configureRX()가 처리합니다.

audio_capture_inmp441_sd/audio_capture_inmp441_sd.ino
  WROOM CAM + INMP441로 녹음하고 보드 뒷면 microSD 슬롯에 WAV를 저장합니다.
  녹음 시간은 코드 위쪽의 RECORD_SECONDS에서 바꿉니다. 기본은 3초입니다.
  수집기나 CollectorLink.h 없이 ESP_I2S, SD_MMC 라이브러리를 사용합니다.
  외장 SD 모듈과 SD용 점퍼선은 필요하지 않습니다.

audio_capture_xiao_usb/CollectorLink.h, audio_capture_inmp441_usb/CollectorLink.h
  두 파일의 내용은 같습니다. 브라우저의 USB 연결 규칙만 처리합니다.
  이 파일은 녹음, 마이크 읽기, 비트 변환, WAV 생성을 구현하지 않습니다.
  녹음 함수는 각 .ino의 공식 recordWAV() 호출에서 직접 확인할 수 있습니다.

오디오 실습 페이지 https://midnightradio.github.io/physical-ai-lab/audio/
  기존과 같은 오디오 수집기입니다. Chrome/Edge에서 엽니다.
  라벨 버튼과 직접 입력, 재생·파형, 1·2·3·5·10초, ZIP 저장을 지원합니다.
  학습용·테스트용 구분 없이 모든 WAV를 audio 폴더에 저장합니다.
  이미 사용 중인 기존 수집기에도 두 USB 예제를 연결할 수 있습니다.

추천 학습 순서
--------------
XIAO와 SD 카드가 있으면 audio_capture_xiao_sd → audio_capture_xiao_usb 순서로 공부합니다.
SD 카드가 없으면 바로 audio_capture_xiao_usb로 시작해도 됩니다.
WROOM과 INMP441을 쓰는 학생은 SD 저장은 audio_capture_inmp441_sd, 브라우저 저장은 audio_capture_inmp441_usb로 시작합니다.
두 보드의 마이크 설정은 별도로 읽고, recordWAV() 이후의 흐름을 비교합니다.

공통 준비
---------
1. Arduino IDE의 보드 매니저에서 esp32 by Espressif Systems 3.3.12를 설치합니다.
2. XIAO는 XIAO_ESP32S3, WROOM 개발보드는 ESP32S3 Dev Module을 선택합니다.
3. 두 보드 모두 PSRAM = OPI PSRAM으로 설정합니다.
   이 교재는 10초까지의 WAV를 RAM에 담을 수 있게 PSRAM 활성화를 확인합니다.
4. Flash Size는 XIAO Sense 8MB, WROOM N16R8 16MB에 맞춥니다.
5. ESP32-S3 직접 USB를 쓰면 USB Mode=Hardware CDC and JTAG,
   USB CDC On Boot=Enabled로 설정합니다.
   WROOM의 USB-UART 포트를 쓰면 USB CDC On Boot=Disabled로 설정합니다.
6. 선택한 실습의 폴더를 통째로 유지하고 그 안의 같은 이름 .ino를 엽니다.
   USB 예제는 CollectorLink.h도 같은 폴더에 있어야 합니다.

XIAO 마이크는 Sense 확장 보드에 있습니다. 일반 XIAO ESP32S3만으로는
내장 마이크를 사용할 수 없습니다. 확장 보드의 체결을 확인합니다.

실습 01: 수집기 없이 SD 카드에 녹음
---------------------------------
1. FAT32로 포맷한 microSD를 Sense 확장 보드의 슬롯에 넣습니다.
2. audio_capture_xiao_sd.ino를 업로드합니다.
3. Arduino 시리얼 모니터를 115200으로 열고 r을 보냅니다.
4. 첫 1초는 예열 녹음입니다. 그다음 “지금부터 3초 동안 녹음합니다”가 뜨면
   말하거나 소리를 냅니다.
5. /recording_1.wav 같은 경로가 표시됩니다. 다시 r을 보내면 다음 파일에 저장합니다.
   기존 파일이 있으면 다음 번호를 찾아 사용하므로 재시작해도 덮어쓰지 않습니다.
6. 저장 완료 후 보드 전원을 끄고 카드를 꺼내 PC에서 WAV를 재생합니다.

이 예제에서 배우는 핵심은 다음 네 줄입니다.

  uint8_t *wav = microphone.recordWAV(RECORD_SECONDS, &wavBytes);
  File file = SD.open(path, FILE_WRITE);
  file.write(wav, wavBytes);
  free(wav);

완전한 예제에는 마이크 시작, 파일 열기, 실패 확인, 파일 닫기도 들어 있습니다.

실습 02: XIAO를 오디오 수집기에 연결
----------------------------------
1. audio_capture_xiao_usb.ino를 업로드합니다.
2. 시리얼 모니터와 플로터를 닫습니다.
3. 오디오 실습 페이지 https://midnightradio.github.io/physical-ai-lab/audio/을 PC용 Chrome 또는 Edge로 열고 보드 연결을 누릅니다.
4. 라벨 버튼을 누르거나 직접 입력하고 녹음 길이를 고릅니다.
5. 녹음 시작을 누른 뒤 “녹음 중” 표시가 뜨면 소리를 냅니다.
   화면의 3초 준비 시간 다음에 마이크 예열 1초가 추가됩니다.
6. 파형과 재생 소리를 확인하고 WAV 또는 전체 ZIP을 저장합니다.

실습 03: WROOM + INMP441을 수집기에 연결
--------------------------------------
전원을 끄고 아래처럼 연결한 뒤 audio_capture_inmp441_usb.ino를 업로드합니다.

  INMP441    ESP32-S3 개발보드
  VDD        3V3
  GND        GND
  SCK/BCLK   GPIO1
  WS/LRCLK   GPIO2
  SD/DOUT    GPIO42
  L/R        GND

숫자는 GPIO 번호입니다. VDD에는 5V를 연결하지 않습니다.
짧은 선을 쓰고 SD-GND 사이 100kΩ 풀다운을 권장합니다.
기존 예제의 GPIO4·5·6은 이 CAM 보드의 카메라와 겹칩니다.
카메라가 연결된 보드에서 사용할 수 있게 마이크를 GPIO1·2·42로 옮겼습니다.
SD 저장 예제와 USB 수집 예제는 같은 배선을 사용합니다. 카메라는 초기화하지 않습니다.
업로드 뒤 수집기로 녹음하고 저장하는 순서는 XIAO USB 실습과 같습니다.

실습 04: WROOM CAM의 내장 SD 슬롯에 저장
---------------------------------------
사진으로 확인한 수업용 CAM 보드는 뒷면에 microSD 슬롯이 있습니다.
FAT32 카드를 이 슬롯에 넣습니다. SD용 외장 모듈과 점퍼선은 사용하지 않습니다.
아래는 보드에 이미 연결된 내부 핀입니다. 여기에 선을 추가로 연결하지 않습니다.

  내장 microSD   보드 내부 GPIO
  CLK            GPIO39
  CMD            GPIO38
  D0             GPIO40

이 슬롯은 공식 SD_MMC 라이브러리의 1비트 모드로 사용합니다.
1비트는 SD 통신 방식이며, 저장되는 소리는 여전히 16비트·모노 WAV입니다.
마이크는 실습 03처럼 SCK=GPIO1, WS=GPIO2, SD=GPIO42, L/R=GND로 연결합니다.
INMP441의 SD는 마이크 데이터 핀이며, SD 카드의 이름과 혼동하지 마세요.
N16R8은 메모리 용량 표기입니다. 다른 형태의 N16R8 보드는 SD 핀이 다를 수 있습니다.

1. FAT32 microSD를 보드 뒷면 슬롯에 넣고 audio_capture_inmp441_sd.ino를 엽니다.
2. 보드는 ESP32S3 Dev Module, PSRAM=OPI PSRAM, Flash Size=16MB로 설정합니다.
   USB 설정은 공통 준비의 직접 USB / USB-UART 구분에 맞춥니다.
3. 업로드한 뒤 시리얼 모니터를 115200으로 열고 r을 보냅니다.
   시작 안내가 안 보이면 모니터를 연 상태에서 보드를 한 번 리셋합니다.
4. “마이크 예열 중” 다음의 “지금부터 녹음합니다”가 뜨면 소리를 냅니다.
5. /recording_1.wav, /recording_2.wav처럼 다음 파일에 저장됩니다.
   저장 완료를 확인한 뒤 보드 전원을 끄고 카드를 PC에서 읽어 재생합니다.

내장 슬롯의 준비와 파일 열기는 다음과 같습니다.

  SD_MMC.setPins(39, 38, 40);  // 순서: CLK, CMD, D0
  SD_MMC.begin("/sdcard", true, false, SDMMC_FREQ_DEFAULT);
  File file = SD_MMC.open(path, FILE_WRITE);

begin()의 true는 1비트 모드이고, false는 실패해도 자동 포맷하지 않는다는 뜻입니다.
SDMMC_FREQ_DEFAULT는 공식 라이브러리에 정의된 20MHz 설정입니다.
SD_MMC.open()의 path는 /recording_1.wav처럼 씁니다. /sdcard를 앞에 붙이지 않습니다.
XIAO 예제의 SD.open()/SD.exists() 대신 SD_MMC.open()/SD_MMC.exists()를 사용하며,
녹음·file.write()·file.close()·free()의 흐름은 같습니다.

두 보드의 SD 예제에서 기본 3초를 10초로 바꾸려면 RECORD_SECONDS를 바꾸고 다시 업로드합니다.

  const int RECORD_SECONDS = 10;

이 예제는 녹음 길이에 맞춰 읽기 대기 시간을 자동으로 늘립니다.
저장 형식은 다른 예제와 같은 16000Hz·16비트·모노 PCM WAV입니다.

코드에서 읽을 순서
-----------------
1. I2SClass microphone;
   공식 라이브러리의 마이크 객체를 만듭니다.

2. setPinsPdmRx() 또는 setPins(), begin()
   어떤 마이크를 어떤 핀과 형식으로 읽을지 정합니다.
   이 설정은 보드와 마이크에 맞는 예제의 값을 사용하면 됩니다.

3. configureRX() — INMP441 예제만 해당
   32비트 입력을 16비트 소리로 변환하도록 라이브러리에 요청합니다.
   직접 비트를 옮기거나 WAV 헤더를 고칠 필요가 없습니다.

4. microphone.recordWAV(seconds, &wavBytes)
   정해진 시간 동안 녹음하고 완성된 WAV를 돌려줍니다.
   begin() 다음의 첫 recordWAV(1, ...)은 예열용으로 버립니다.
   collectorRecording(seconds) 다음의 호출이 저장할 실제 녹음입니다.

5. file.write(wav, wavBytes) 또는 collectorSendWav(wav, wavBytes)
   같은 WAV 데이터를 SD 파일로 쓰거나, PC의 수집기로 보냅니다.
   이후 프로젝트에서 저장·전송 부분을 교체할 때 참고할 수 있습니다.

6. free(wav)
   녹음에 사용한 메모리를 돌려줍니다. 반복 녹음할 때 꼭 필요합니다.

처음 보는 표기 세 가지
--------------------
size_t wavBytes = 0;
  WAV 파일의 크기를 바이트 단위로 담는 변수입니다.

uint8_t *wav
  WAV 파일 내용이 들어 있는 메모리 공간을 가리킵니다.
  이 실습에서는 직접 주소를 계산하지 않고 라이브러리와 write()에 전달합니다.

&wavBytes
  recordWAV()가 파일 크기를 wavBytes 변수에 써 줄 수 있도록 전달하는 표기입니다.

다른 프로젝트로 가져갈 때
-------------------------
마이크 설정 → recordWAV() → 저장 또는 전송 → free() 순서를 가져가면 됩니다.
독립 프로젝트에서는 CollectorLink.h 없이 공식 API만으로 녹음할 수 있습니다.
SD 저장은 audio_capture_xiao_sd 또는 audio_capture_inmp441_sd 예제를 참고합니다.
버튼이나 센서가 녹음을 시작하게 하려면
audio_capture_xiao_sd의 loop()에서 r 입력을 확인하는 부분을 버튼·센서 조건으로 바꾸면 됩니다.

setTimeout(12000)은 녹음 길이가 아니라 읽기를 기다릴 수 있는 최대 시간입니다.
실제 녹음 길이는 recordWAV()의 첫 번째 값으로 정합니다.
특히 PDM으로 10초를 읽을 때 기본 1초 대기 제한으로 실패하지 않도록 넣었습니다.
WROOM SD 예제는 setTimeout((RECORD_SECONDS + 2) * 1000)으로 길이에 맞춰 설정합니다.

이 방식은 WAV 전체를 RAM에 담는 짧은 녹음용입니다.
16kHz·16비트·모노에서 10초 WAV는 320,044 bytes입니다.
recordWAV()가 실행되는 동안 loop()의 다음 작업은 기다립니다.
몇 분씩 녹음하거나 녹음 중 다른 일을 동시에 해야 하는 프로젝트로 확장할 때는
스트리밍 방식의 arduino-audio-tools 같은 라이브러리를 이어서 검토할 수 있습니다.

Edge Impulse로 업로드
--------------------
ZIP을 풀고 audio 폴더 또는 나중에 정리한 폴더를 Studio의 Upload data에서 선택합니다.
파일명에서 라벨을 추론하면 yes.s01.…wav의 라벨은 yes입니다.
데이터 용도와 분할은 수집 후 정합니다. 녹음 중에는 용도를 선택하지 않습니다.
