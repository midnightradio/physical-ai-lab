보드별 USB·SD 예제 4개와 사용 안내가 들어 있습니다. 아래 웹 수집기에는 USB 예제를 올려 연결하세요.

  1. 코드 ZIP을 압축 해제하고 사용할 예제 폴더 안의 같은 이름 .ino를 엽니다. USB 예제는 CollectorLink.h도 같은 폴더에 둡니다.
  2. 보드 매니저에서 esp32 by Espressif Systems 3.3.12를 설치합니다. 녹음은 공식 ESP_I2S.recordWAV()를 사용하며, 추가 오디오 라이브러리는 설치하지 않습니다.
  3. 보드는 XIAO이면 XIAO_ESP32S3, WROOM이면 ESP32S3 Dev Module로 선택합니다. PSRAM = OPI PSRAM을 활성화하고 Flash는 XIAO 8MB, WROOM N16R8 16MB로 선택합니다.
  4. 직접 USB는 USB Mode = Hardware CDC and JTAG, USB CDC On Boot = Enabled. USB-UART 포트는 USB CDC On Boot = Disabled로 설정합니다.
  5. USB 예제 업로드 후 시리얼 모니터·플로터를 닫고 아래에서 보드를 연결합니다. SD 예제는 시리얼 모니터를 115200으로 열어 r을 보냅니다.

WROOM의 변경된 INMP441 배선: SCK=GPIO1, WS=GPIO2, SD=GPIO42, L/R=GND, VDD=3V3, GND=GND. XIAO는 Sense 확장 보드의 내장 PDM 마이크를 사용합니다.

SD 예제는 보드의 microSD 슬롯을 사용합니다. WROOM은 내부 CLK39·CMD38·D0 40, XIAO는 내부 CS21이며 SD용 점퍼선은 추가하지 않습니다. SD 녹음 길이는 RECORD_SECONDS로 지정합니다.

1. 보드 연결

먼저 자신의 보드에 맞는 USB 예제를 업로드하고 시리얼 모니터와 플로터를 닫으세요.
이 페이지를 PC용 Chrome 또는 Edge로 열고, 보드의 USB 포트를 선택하세요.

연결 전

2. 라벨을 선택하고 녹음

영문으로 시작 · 영문, 숫자, _ 또는 - · 최대 32자

yes / no: 한 파일에 한 단어만 말하세요. silent: 말하지 않고 실제 주변 소리를 녹음하세요.
모든 WAV를 audio 폴더에 모아 저장합니다. 데이터 용도는 수집 후 정리하세요.

보드를 연결해 주세요.

입력은 ESP32에 연결된 마이크입니다.

3. 녹음 확인 · 저장

들어 보고 잘못된 샘플은 삭제하세요. 창을 닫거나 새로고침하기 전에 ZIP을 저장하세요.

아직 녹음한 샘플이 없습니다.

Edge Impulse에 업로드

  1. 저장한 ZIP을 압축 해제합니다.
  2. Edge Impulse Studio에서 프로젝트 → Data acquisition → Upload data를 엽니다.
  3. 수집을 마친 후 데이터 용도를 정리하고, Select a folder로 audio 폴더 또는 정리한 폴더를 선택합니다.
  4. 파일명에서 라벨을 추론하는 옵션을 사용해 업로드합니다. yes.s01.…wav의 라벨은 yes입니다.
  5. 업로드할 데이터의 용도에 맞춰 업로드 대상을 선택합니다.
  6. 샘플의 주파수 16000 Hz, 길이, 라벨을 확인합니다. Create impulse의 창 길이는 녹음 길이에 맞춥니다.

이 수집기는 WAV 파일을 PC에 저장합니다. Edge Impulse 업로드는 위의 Studio 화면에서 진행하세요.
