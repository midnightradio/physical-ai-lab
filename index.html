BEFORE YOU START

처음이라면 이 순서로.

보드 코드는 실습마다 다릅니다.
사용할 실습의 ZIP을 선택하세요.

  1. 코드 다운로드ZIP을 압축 해제하고 폴더 안의 .ino 파일을 Arduino IDE에서 엽니다.
  2. 보드에 업로드자신의 보드와 USB 설정을 선택합니다. 자세한 안내는 ZIP의 README에 있습니다.
  3. 웹페이지에서 수집시리얼 모니터와 플로터를 닫고 실습 페이지에서 USB 보드를 연결합니다.

수집한 데이터는 이 브라우저 창에 보관됩니다. 실습을 마치거나 페이지를 이동하기 전에 파일로 저장하세요.
